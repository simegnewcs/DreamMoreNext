# DreamMore Platform

DreamMore is a full-stack Next.js platform for digital agency services, online education, and operational management. It combines a marketing website, course catalog, LMS workflows, and admin tools into a single product experience.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the application.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- MySQL
- NextAuth / JWT authentication
- Cloudinary for media uploads
- Nodemailer for email workflows

## Project Goals

- Showcase digital services and portfolio work
- Deliver online courses and manage LMS content
- Support student enrollment and application workflows
- Provide administrators with operational dashboards and content tools
