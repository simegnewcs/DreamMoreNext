## Quick Start

1. Install dependencies with `npm install`.
2. Configure your environment variables in `.env.local`.
3. Create or update the MySQL database using the SQL scripts in `src/lib` and `scripts`.
4. Run the app with `npm run dev`.

## Project Summary

DreamMore is a multi-purpose digital platform focused on:
- agency services and digital transformation
- online course and LMS delivery
- application management for course enrollment
- blog, portfolio, testimonials, and team content
- admin dashboards for operations and content management
