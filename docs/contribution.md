# Contribution Guide

## How New Developers Should Contribute
1. Review the documentation in this folder.
2. Create a feature branch from the main branch.
3. Make focused changes with clear commit messages.
4. Verify the app builds locally before opening a pull request.

## Pull Request Process
- Summarize the change and rationale.
- Include any relevant screenshots or notes for UI changes.
- Mention affected areas and any environment changes.
- Ensure no secrets or local-only configuration are committed.

## Branching Strategy
- `main` for stable production-ready code
- `feature/*` for new enhancements
- `fix/*` for bug fixes
- `docs/*` for documentation updates
