# Future Development

## Known Limitations
- Some modules appear to rely on direct SQL queries and may benefit from stronger abstraction layers.
- The current documentation should be expanded as new features are added.
- Some areas may need more formal validation and test coverage.

## Technical Debt
- Mixed data access patterns across route handlers and helper modules
- Some schema and migration logic may need standardization
- Additional API versioning and error-handling conventions could improve maintainability

## Suggested Improvements
- Add automated tests for auth, course enrollment, and admin workflows
- Introduce a formal migration framework for database changes
- Improve API consistency and validation schemas
- Add monitoring tooling and operational dashboards

## Roadmap
- Expand LMS capabilities and analytics
- Improve admin workflows and role-based access controls
- Introduce stronger content moderation and publishing controls
- Improve performance and observability for production monitoring
